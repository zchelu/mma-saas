# Exporting Your Member List

Before you can import your roster into KombatDesk, you need a CSV export from your current gym-management platform. Find your platform below and follow the steps.

---

## PushPress

1. Log in to your PushPress admin dashboard.
2. Go to **Members** in the left sidebar.
3. Use the filters at the top if you only want a subset (e.g. Active only) — otherwise leave filters off to export everyone.
4. Click **Export** (usually top-right of the member list).
5. Choose **CSV** as the format.
6. PushPress will either download the file directly or email you a link — check your inbox if it doesn't download immediately.
7. Save the file somewhere you can find it (e.g. your Desktop) — you'll upload this exact file to KombatDesk.

---

## Zen Planner

1. Log in to Zen Planner and go to the **People** menu.
2. Select **Prospects/Members** (or just **Members**, depending on your account setup).
3. Click **Search** with no filters applied to pull your full list, or narrow it with the search filters if needed.
4. Once results load, look for the **Export** or **Download** icon above the results table.
5. Select **CSV** (Zen Planner sometimes calls this "Export to Excel" — CSV is still fine, or open it and re-save as CSV if you're only given .xlsx).
6. Save the download.

---

## Kicksite

1. Log in to Kicksite and go to **Students** (sometimes labeled **Members**).
2. Make sure you're viewing the full list — clear any status filters (e.g. "Active Only") if you want every student, past and present.
3. Look for an **Export** button, usually above the student table on the right.
4. Choose **CSV** from the export options.
5. The file will download to your computer automatically.

---

## Gymdesk

1. Log in to your Gymdesk admin panel.
2. Go to **Members** from the main menu.
3. Clear any active filters if you want your complete roster.
4. Click the **Export** or **⋮** (more options) menu above the member table.
5. Select **Export to CSV**.
6. Gymdesk will generate the file and either download it or send it to your account email — check both.

---

## After You Export

- Don't edit the column headers in the file — upload it as-is.
- If your export has thousands of rows, that's fine — the import tool handles large files.
- If a student's belt rank looks blank or wrong in your export, don't worry about fixing it by hand first — the import tool will flag anything it can't confidently match so you can review it before it's saved.
