WHY THE VERTICAL ONES ARE CROPPED, NOT SHRUNK
Shrinking the whole dashboard into a 9:16 frame makes the member names an
illegible smear on a phone. The vertical files crop into the rows instead, so
the names and "9 days ago" actually read. You lose surrounding context; you
gain a shot someone can actually parse while scrolling.

WHAT IS DELIBERATELY NOT IN FRAME
  - "Members Brought Back — 0 members brought back in this range"
  - the kiosk URL further down the dashboard, which contains the gym id
  - the browser scrollbar

THESE ARE STATIC HOLDS, NOT PANS
Block 3's script calls for landing on the list and saying nothing for a beat.
Movement fights that. Trim to whatever length you need; there is no motion to
cut against.
